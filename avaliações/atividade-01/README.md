# Atividade 01

Criar e configurar um repositório no GitHub para o armazenamento das atividades da disciplina de Sistemas Operacionais (SO-262).

## Descrição

Nesta atividade foram realizadas as seguintes etapas:

* Criação de uma conta no GitHub;
* Criação do repositório **so-262**;
* Organização da estrutura de pastas do repositório conforme as orientações da disciplina;
* Criação da pasta `avaliações`, contendo as subpastas `atividade-01` até `atividade-10`, cada uma com seu respectivo arquivo `README.md`.

O repositório será utilizado para armazenar e documentar as atividades desenvolvidas ao longo da disciplina.
